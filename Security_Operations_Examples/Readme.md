# Security Operations Examples

Hands-on Security Operations Center (SOC) work developed during the BeTek / MAKAIA Cybersecurity Bootcamp. This category groups two complementary sides of day-to-day security operations: real-time monitoring with a SIEM, and structured incident response.

## Subcategories

- `SIEM_ELK_Stack/`: end-to-end build of a functional SIEM using the Elastic Stack (Elasticsearch, Kibana, Winlogbeat, Metricbeat), with log ingestion from Windows and Linux, dashboards, and controlled event generation for detection testing.
- `Incident_Response_PICERL/`: a full incident response plan for a ransomware scenario, structured around the six phases of the SANS PICERL framework.

## Competencies demonstrated

- Real-time event monitoring and log analysis across Windows and Linux sources.
- SIEM deployment, configuration, and dashboard design.
- Incident lifecycle handling: preparation, identification, containment, eradication, recovery, and lessons learned.
- Severity classification, escalation, and crisis communication.
