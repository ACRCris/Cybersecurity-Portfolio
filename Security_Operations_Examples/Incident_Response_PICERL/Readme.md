# Activity Summary

Portfolio Activity: **Incident response plan using the SANS PICERL framework**, from the "Security Incident Response" submodule of the BeTek / MAKAIA Cybersecurity Bootcamp. *Team activity.*

I designed a practical incident response plan for a **ransomware scenario** involving credential compromise, lateral movement, and data exfiltration, applied to a mid-sized digital-services company (fictitious DataMarket S.A.S.) running a hybrid Windows/Linux infrastructure with a SIEM.

## Objectives accomplished

Built the response plan across the six phases of **SANS PICERL**:

- **Preparation**: minimum readiness list — response-team roles, key contacts, required tools, log sources, backups, severity criteria, escalation procedures, and crisis communication channels.
- **Identification (Detection & Analysis)**: initial incident record — confirming the incident, classifying its type, identifying affected assets, and rating severity.
- **Containment**: short- and long-term containment actions.
- **Eradication**: removing the threat and its persistence.
- **Recovery**: restoring services safely.
- **Lessons learned**: post-incident review and improvements.

## Folder Structure and Status

- `Incident_Response_Plan_PICERL.pdf`: complete plan documenting the six PICERL phases against the ransomware scenario, including the severity matrix and incident fiche.

## Frameworks

SANS PICERL incident response lifecycle; severity classification and escalation.
