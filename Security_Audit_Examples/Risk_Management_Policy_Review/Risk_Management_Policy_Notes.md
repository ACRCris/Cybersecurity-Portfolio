| Policy Section | Recommended Change(s) | Reasoning |
| :---- | :---- | :---- |
| Access Control | Require workstations to lock automatically after a defined period of inactivity, and keep the lock in place until the user re-authenticates. | The current policy is non-compliant with AC-11 a. and b., which require a device lock triggered by inactivity and retained until identification and authentication are re-established. |
| Access Control | Prohibit non-privileged users from executing privileged functions. | The current policy is non-compliant with AC-6(10), which prohibits non-privileged users from executing privileged functions. |
| Awareness and Training | Implement role-based training tailored to each employee's assigned roles and responsibilities, delivered before access to the system is authorized. | The current policy is non-compliant with AT-3 a., which requires role-based training matched to assigned duties rather than a single identical course for all personnel. |
| Awareness and Training | Update training content at a defined frequency and following defined events, such as incidents, audit findings, or system changes. | The current policy is non-compliant with AT-3 b. and AT-2 c., which require training content to be reviewed and updated periodically and after defined events. |
| Configuration Management | Establish explicit policies governing which software users may and may not install, enforce them through defined methods, and allow user installation only with explicit privileged status. | The current policy is non-compliant with CM-11 a., b., and c., and with CM-11(2), which restricts software installation to users granted explicit privileged status. |
| Identification and Authentication | Remove the prohibition on spaces and punctuation, and allow users to select long passwords and passphrases containing spaces and all printable characters. | The current policy is non-compliant with IA-5(1)(f), which requires that users be allowed to choose long passwords and passphrases including spaces and all printable characters. |
| Physical and Environmental Protection | Remove individuals from the server room access list when access is no longer required, and review the list at a defined frequency. | The current policy is non-compliant with PE-2 d., which requires removal from the facility access list when access is no longer required, and with PE-2 c., which requires periodic review of that list. |
| Risk Assessment | Define the frequency for vulnerability scanning, and require the team to analyze scan results, remediate legitimate vulnerabilities within defined response times, and share findings with designated personnel. | The current policy is non-compliant with RA-5 a., c., d., and e. Scanning without defined frequency or a remediation obligation identifies risk without reducing it. |
| System and Information Integrity | Identify the external sources from which security alerts and advisories are received, disseminate them to all affected roles rather than the security team alone, and implement security directives within established time frames. | The current policy is non-compliant with SI-5 a., c., and d., which require receiving alerts from defined external organizations, disseminating them to defined personnel and organizational elements, and implementing directives within established time frames. |
