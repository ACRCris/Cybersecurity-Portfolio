# Activity Summary

Portfolio Activity: **Network services design and diagnosis in Cisco Packet Tracer**, a six-phase workshop from the "Network Fundamentals" module of the BeTek / MAKAIA Cybersecurity Bootcamp.

Design, implementation, and diagnosis of a segmented network with core services, reinforcing the TCP/IP foundation required for security operations.

## Objectives accomplished

- Designed and connected the topology (switches, router, hosts) with **static IPv4 addressing** and gateway configuration.
- Implemented core services: **DHCP, DNS, and HTTP**, including a custom web page and name resolution.
- Performed **diagnosis** both inside Packet Tracer and on the real operating system, by area (administration, support, servers).
- Related the exercise to the **OSI and TCP/IP models and encapsulation**, including why the MAC address must be resolved (ARP) before sending ICMP.

## Folder Structure and Status

- `Network_Design_Workshop.pdf`: unified six-phase report covering topology, addressing, services, diagnosis, and the OSI/TCP-IP relationship.

## Tools

Cisco Packet Tracer; DHCP, DNS, HTTP; ICMP/ARP; OSI and TCP/IP models.
