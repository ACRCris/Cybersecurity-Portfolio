# Offensive Security Examples

Offensive-security work developed during the BeTek / MAKAIA Cybersecurity Bootcamp, performed in controlled lab environments for educational purposes. Understanding how attacks unfold from the attacker's side directly improves defensive work: it clarifies what to look for in logs, alerts, and network traffic.

## Subcategories

- `Pentesting_CTF_HackLabs/`: two Capture-The-Flag laboratories following the standard pentesting methodology (reconnaissance, exploitation, evidence), covering OSINT, service exploitation, network traffic capture, and hash cracking.
- `Reverse_Shell_Lab/`: a minimal proof-of-concept reverse-shell script used to study command-and-control behavior in an isolated lab.

## Ethical note

All activities were carried out in isolated, controlled environments against intentionally vulnerable targets provided for training. No real systems were accessed without authorization. The purpose is defensive understanding and secure-development awareness.

## Competencies demonstrated

- Reconnaissance and OSINT.
- Service enumeration with Nmap; credential attacks with THC-Hydra.
- Network traffic capture and analysis with Wireshark; HTTP Basic Auth and NTLM hash extraction and cracking.
- Awareness of command-and-control mechanics from a defender's perspective.
