# Activity Summary

Portfolio Activity: **Threat, social-engineering, and APT analysis**, a graded evaluation with defense from Module 3 of the BeTek / MAKAIA Cybersecurity Bootcamp.

A 100-point assessment analyzing real-world attack evidence, attack scenarios, notable historical incidents, and defensive measures.

## Objectives accomplished

- **Evidence analysis**: identified indicators in a fraudulent banking email, a network log, and an SMS impersonating the Colombian tax authority (DIAN).
- **Attack scenarios**: analyzed a vishing "support call," a malicious tender document, and performed rapid vector classification.
- **Real-world cases**: analyzed **SolarWinds (2020)**, **WannaCry (2017)**, and the **Twitter (2020)** compromise.
- **Defensive measures**: designed a **layered anti-phishing plan** and a **response plan for an active APT**.

## Folder Structure and Status

- `Threat_and_APT_Analysis.pdf`: the full graded submission and defense, covering the four sections above.

## Competencies

Indicator-of-compromise identification, social-engineering recognition, APT awareness, and layered defensive design.
